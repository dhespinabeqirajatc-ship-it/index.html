# Workiva XBRL Tagging Demo

A self-contained HTML/CSS/JavaScript prototype based on the supplied XBRL workflow screenshots.

## Included interactions
- Switch between the annual report and KVK Mandatory Facts report
- Toggle **Show XBRL** to reveal green tagged cells and dotted calculation indicators
- Open **XBRL Document Generations** from the bottom-right icon
- Right-click the grey 2025 Revenue cell and choose **Create Fact**
- Select concept, dimension, member and fiscal date
- Apply the fact so the cell becomes XBRL-tagged
- Generate a new simulated document generation

## Run
Open `index.html` directly, or run `python -m http.server 8000` in this folder.

This is a simulated training/demo interface and is not an official Workiva product.
