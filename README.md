# Workiva-style XBRL Tagging Demo

Open `index.html` in a desktop browser.

## Guided interaction

1. Turn on **Show XBRL**.
2. Right-click the grey 2025 Revenue cell.
3. Select **Create Fact**.
4. Choose the Revenue concept.
5. Choose the bookmarked consolidated axis and member.
6. Add the FY 2025 date range.
7. Use the bottom-right generations icon or **Generate**.
8. Open the **KVK Mandatory Facts** document tab.

This is a front-end simulation and is not an official Workiva product.
